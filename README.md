# Docker Interview Preparation

Topic-wise Docker interview preparation notes for developers, with a focus on MERN stack, AWS, and Kubernetes.

## Files

- **[Docker Interview Questions](./docker-interview-question.md)** — 200 questions organized into 13 topics, from fundamentals to production scenarios.

1. Docker Fundamentals
2. Essential Docker Commands
3. Dockerfile
4. Images and Image Builds
5. Containers and Lifecycle
6. Volumes and Data Persistence
7. Docker Networking
8. Docker Compose
9. Docker with MERN Stack
10. Security and Best Practices
11. Performance and Production
12. AWS, CI/CD, and Kubernetes
13. Scenario-Based Questions

## Study approach

Start with fundamentals and commands, then practise Dockerfiles, volumes, networking, and Compose. Finish with MERN deployment, security, and scenario-based questions.

Answers can be added separately in English interview-definition + Hinglish explanation + practical example format.

## Safety note

Use test environments for destructive commands. Never commit passwords, API keys, access tokens, production credentials, or .env files.
